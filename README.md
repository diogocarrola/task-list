# Task List Application

A simple task management web app built with vanilla JavaScript, demonstrating core frontend concepts.

## Features

- **Add Tasks** - Quick entry with Enter key or Add button
- **Mark Complete** - Visual strikethrough with checkbox toggle
- **Delete Tasks** - Clean removal with trash icon
- **Dynamic Scrollbar** - Auto-adjusting based on content height
- **Responsive Design** - Works seamlessly on desktop and mobile devices

## Tech Stack

- **Frontend**: HTML5, CSS3, Vanilla JavaScript (ES6+)
- **Icons**: Unicode Icons
- **Styling**: Custom CSS with modern design principles

## Installation & Usage

1. Clone the repo:
   ```bash
   git clone https://github.com/diogocarrola/task-list.git
   ```
2. Open `index.html` in your browser.

## Usage

- Type a task and press Enter or click Add
- Check the box to complete a task
- Click trash to delete a task
